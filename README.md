# 📋 ToDo Manager — Just get things done

> **One file. One second. No magic. Just order in your head.**

This is not "yet another to-do list". This is a place where your tasks stop being chaos and become a list of things you'll **actually** get done today.

---

## ⚡️ What's inside (plain and simple)

- ✅ **Add tasks** — fast, no useless fields
- 🔥 **Priorities** — what's important stays on top
- 🎨 **Smooth animations & gradients** — a pleasure to use
- 🧹 **Filters** — show only what you need right now
- 💾 **Auto-save** — nothing gets lost, even if your PC crashes

---

## 🚀 How to start

1. Download the [pre-release](https://github.com/golybkovaa646-byte/ToDo-Manager/releases/tag/0.3V)
2. Run `ToDo Manager.exe`
3. Add your first task
4. Done. You're already more organized than 90% of people.

---

## 🧠 Why it looks and feels this way

Because I believe:

> *"A good tool should never make you think about how it works. It should just work."*

The UI is minimal, but every detail — from the animations to the card shadows — is designed to make you **feel good** while using it. Even when you're just looking at your list.

---

## 🛠️ Tech stack (for those who care)

- **Platform:** .NET 10 / WPF
- **Architecture:** MVVM + Dependency Injection
- **Storage:** SQLite with Entity Framework Core
- **Distribution:** Self-contained, single `.exe` for Windows
